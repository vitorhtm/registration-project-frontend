# Cadastro em Etapas – Frontend

Frontend de um fluxo de cadastro em etapas (wizard) usando **Next.js (App Router)** e **TypeScript**.

## Funcionalidades

- Cadastro dividido em etapas
- Persistência do progresso
- Revisão final dos dados
- Tela de sucesso ao concluir
- Validações básicas no frontend
- Tratamento de erros da API

## Tecnologias

- Next.js 13+ (App Router)
- React
- TypeScript
- Context API
- Axios
- CSS tradicional / inline styles
